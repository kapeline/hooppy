Заливка в Хуппи

Кидаешь видео — они сами уходят в Хуппи с подписями по кругу и временем по правилам.

1. Проект

2. Видео

Перетащи видео сюда или нажми, чтобы выбрать
MP4 / MOV. Порядок — по названию файла (rls_01, rls_02…)
Сжатие идёт прямо в браузере, по одному файлу. Файлы больше 400 МБ уходят как есть. Если сжатие не получилось или файл не стал меньше — уходит оригинал.

3. Время

Пусто — как раньше (сегодня по оставшимся окнам). Если число задано, сегодня уйдёт ровно столько видео, равномерно по промежутку; «сразу» входит в это число. 0 — сегодня ничего.
Дата пустая — со следующего дня (если задано «сегодня») или сразу. «С вечера» — в первый день только последнее окно. Дальше — по окнам ниже, по умолчанию 2 в день.
В каждом окне время выбирается случайно. Сегодняшние окна, которые уже прошли, пропускаются.

Слежка за публикациями

Пока вкладка открыта, сайт проверяет каждый пост через 3, 10, 20, 30, 40, 50 и 60 минут после выхода. Ошибку нужно увидеть два раза подряд, потом он перевыкладывает пост на упавшую страницу с подписью и хештегами. Не получилось — сигнал.

Токен Хуппи

Токен хранится только в этом браузере и отправляется только на api.hooppy.ru. На самом сайте (в коде) его нет.

Сигнал о проблемах

Если видео совсем не выкладывается, сайт включит звук, замигает вкладкой и покажет уведомление. Нажми кнопку один раз, чтобы браузер разрешил звук и уведомления.
